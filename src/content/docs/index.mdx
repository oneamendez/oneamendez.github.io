## Why crate

<CardGrid>
	<Card title="A real computer in your pocket" icon="laptop">
		Not a remote desktop or a cloud VM: the whole operating system runs on the
		iPhone, works offline, and your files stay on it.
	</Card>
	<Card title="Real distributions" icon="puzzle">
		Stock arm64 Linux with its own package manager, so what runs on an Arm
		laptop installs as it is: browsers, developer tools, coding agents like
		Claude Code, CAD apps.
	</Card>
	<Card title="Built for speed" icon="rocket">
		The [crate engine](/crate/engine/) is written from scratch in Rust: an
		arm64-to-arm64 translator that copies most guest instructions as they are
		and rewrites only what touches the machine.
	</Card>
	<Card title="GPU-accelerated" icon="star">
		The guest's OpenGL runs on the iPhone's GPU, through virglrenderer, ANGLE
		and MoltenVK: desktops composite in hardware, and 3D apps render on it.
	</Card>
	<Card title="Made for the phone" icon="approve-check">
		Touch is a tablet, a key row adds Esc, Ctrl, Super, Tab, function keys and
		arrows, and the desktop follows the phone as it turns.
	</Card>
	<Card title="Open source" icon="open-book">
		The app and the engine are MPL-2.0, and every library they carry is built
		from upstream source.
	</Card>
</CardGrid>

## Fast, from the engine up

A fixed set of workloads in a Debian guest, on an M3 MacBook Air. The whole pass,
in seconds; shorter is faster:

<div class="speed">
	<div class="speed-row"><span>crate</span><div class="speed-bar crate" style="width: 18.8%"></div><span>24.5 s</span></div>
	<div class="speed-row"><span>QEMU's TCG</span><div class="speed-bar" style="width: 100%"></div><span>130.5 s</span></div>
	<div class="speed-row"><span>Native (hvf)</span><div class="speed-bar" style="width: 7%"></div><span>9.1 s</span></div>
</div>

On an iPhone Duo, the desktop is drawn 6.3 s after the app opens.

## Try it

crate needs JIT, which iOS gives only to an app a debugger has attached to, so
it can't come from the App Store. Each release has an IPA you sign with your own
Apple account on a Mac.
