crate can't come from the App Store: it needs JIT, which iOS gives only to an app
a debugger has attached to, and only apps signed for development can be attached
to. So each [release](https://github.com/oneamendez/crate-ios/releases) has an
unsigned IPA, `crate-unsigned.ipa`, which you sign with your own Apple account on
a Mac, then install on your iPhone or iPad.

## The quick way: ask Claude Code

On a Mac with Xcode, with your iPhone connected by cable, start
[Claude Code](https://claude.com/claude-code) and paste:

```text
Install crate on my iPhone from https://github.com/oneamendez/crate-ios,
following its INSTALL.md. Download the latest release's crate-unsigned.ipa
and verify it with `gh attestation verify`. Sign it with my own Apple
development certificate using the repository's Scripts/sign-ipa.sh, under a
bundle ID of mine. If my account allows it, give the app ID the Increased
Memory Limit and Extended Virtual Address Space capabilities; it's fine
without them. Then install it on my iPhone and tell me how to turn on JIT.
```

It asks you for what only you can do, such as signing in to your Apple account
in Xcode. The steps below are what it follows, if you'd rather do it yourself.

## What you need

- A Mac with Xcode, signed in to your Apple account (Xcode › Settings ›
  Accounts). A paid Apple Developer Program membership gives profiles that last
  a year; a free account's last 7 days, after which you sign again.
- An iPhone or iPad with Developer Mode on (Settings › Privacy & Security ›
  Developer Mode), connected to the Mac and trusted.
- Optionally, the [GitHub CLI](https://cli.github.com) (`gh`), to check where the
  IPA came from.

## Step by step

<Steps>

1. **Download the IPA.**

   ```sh
   curl -LO https://github.com/oneamendez/crate-ios/releases/latest/download/crate-unsigned.ipa
   gh attestation verify crate-unsigned.ipa --repo oneamendez/crate-ios
   ```

   The second command checks that crate's own GitHub workflow built the file.
   Each release's notes also list its SHA-256.

2. **Make development profiles for your bundle ID.** Pick a bundle ID under your
   name, such as `com.yourname.crate`. crate's JIT helper lives inside the app as
   `com.yourname.crate.jithelper`. The easiest way to get both profiles is to let
   Xcode make them:

   - In Xcode, File › New › Project › iOS App. Set the Bundle Identifier to
     `com.yourname.crate` and the Team to yours.
   - Optional, but it lets VMs use more memory: in the target's Signing &
     Capabilities, add **Increased Memory Limit** and **Extended Virtual Address
     Space**. If your account can't add them, leave them out; crate runs without
     them.
   - Pick your iPhone as the run destination and Run once. Xcode registers the
     bundle ID and creates the profile. You can delete the app afterwards.
   - Do the same for `com.yourname.crate.jithelper`, with no capabilities. You
     can skip this one if Xcode has already made your team a wildcard profile.

   <Shot alt="Xcode's Signing and Capabilities tab with Increased Memory Limit and Extended Virtual Address Space added" todo="Mac: Xcode's Signing & Capabilities with the two memory capabilities. Blur or crop your team name and email." />

3. **Sign and install.** Get the signing script and your device's identifier:

   ```sh
   curl -LO https://raw.githubusercontent.com/oneamendez/crate-ios/main/Scripts/sign-ipa.sh
   chmod +x sign-ipa.sh
   xcrun devicectl list devices
   ```

   Then sign and install in one step:

   ```sh
   BUNDLE_ID=com.yourname.crate ./sign-ipa.sh crate-unsigned.ipa --install <your device's identifier>
   ```

   It says which profiles it used, and whether the memory entitlements went in.
   It also leaves `crate-signed.ipa` beside the download, which you can install
   any other way.

4. **Turn on JIT.** Open crate and go to Settings. The built-in StikJIT is the
   default: Set Up JIT pairs the iPhone with crate and walks you through
   LocalDevVPN, which it needs. [Turning on JIT](/crate/guides/jit/) has both methods.

   <Shot alt="crate's Settings with JIT turned on" todo="iPhone, portrait: Settings › JIT showing On, with Set Up JIT and the launch toggle." />

5. **Install a VM.** In the Install tab, pick a distribution and a memory size,
   then Install; crate asks for the account to create in the VM. Once the
   desktop is up, its own display settings change the resolution: 1280 × 800
   fits more on screen than the default.

</Steps>

<Aside type="tip" title="Less memory without the entitlements">
	Without the memory entitlements iOS gives crate less memory, so pick a smaller
	size. Settings › Memory shows the limit iOS gave it.
</Aside>

## When something goes wrong

- **"no development profile"**: step 2 hasn't made one for that bundle ID, or it
  expired. Run the Xcode project again.
- **The install fails with a provisioning error**: the profile doesn't include
  your device. Run the Xcode project once with the device connected.
- **JIT won't turn on**: the profile has to be a development one, which allows a
  debugger to attach (get-task-allow); `sign-ipa.sh` warns when it doesn't.
- **Signed, but it stopped opening**: the profile expired (7 days on a free
  account). Sign and install again; your VMs stay.
