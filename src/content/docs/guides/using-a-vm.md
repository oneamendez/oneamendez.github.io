## Starting and stopping

Each VM has a card on the Home tab, with the screen it showed when it last
stopped. **Start** boots it. The card's menu has the VM's settings and Delete.

Shut the VM down from inside its desktop when you can. Stopping it from crate
ends it at once, as pulling the plug on a computer would.

## Touch, keyboards and the key row

- **Touch** works as a tablet: the pointer goes where you touch.
- **A hardware keyboard** types into the VM as it is.
- **The on-screen keyboard** has a key row above it with Esc, Ctrl, Super, Tab,
  function keys and arrows.
- **A mouse or trackpad on iPad** moves the desktop's pointer, with wheel
  scrolling and right and middle click.

## Screen size

The desktop follows the iPhone as it turns. The VM
sets its own resolution in its display settings: 1280 × 800 fits more on screen
than the default (see [Tips](/crate/guides/tips/)). On a monitor, see [External monitor](/crate/guides/external-monitor/).

## The serial console

The VM's serial console is a tab away from its desktop: a plain terminal, and
the place to watch the VM boot.

## Updating the VM

Update the VM's packages as you would on any computer. One exception: the VM
can't update its own kernel yet. See [Known issues](/crate/guides/known-issues/).
